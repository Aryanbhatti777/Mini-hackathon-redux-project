# Mini Todo Application with Redux Toolkit

A task management web application built with React 19, Redux Toolkit, and Vite.

## Features

- Task Creation: Add tasks with a title and description.
- Task Completion: Mark tasks as completed.
- Task Editing: Edit task title and description in place.
- Task Deletion: Delete individual tasks or clear all tasks at once.
- Local Storage Persistence: Automatically preserves task state in browser storage across page reloads.

## Tech Stack

- React 19
- Redux Toolkit (@reduxjs/toolkit)
- React-Redux
- Vite

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
